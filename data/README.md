# data/

This folder should contain the following files, generated by running
`scripts/export_data_for_streamlit.py` as a new cell at the end of your
Colab notebook:

| File | What it is |
|---|---|
| `raci_processes.parquet` | The raw RACI Excel (`df`), including the `Semantic_Document` column |
| `structured_raci.parquet` | The exploded one-row-per-role-per-process table (`structured_df`) |
| `embeddings.npy` | bge-m3 embeddings, one row per RACI process |
| `embedding_process_ids.npy` | The process ID matching each embedding row |
| `jabatan_tugas.pkl` | Dict of `{jabatan_name: [list of Tugas Pokok strings]}` |

`tugas_pokok_embeddings_cache.pkl` is intentionally **not** bundled here —
the app computes and caches those embeddings lazily at runtime instead (see
the main README for why).
